# How to update doc

- Run `nvm use 24`
- Run `npm install --legacy-peer-deps`
- Run `npm run build`
- Run `gatsby develop` in this folder
- Edit the files

# Deploy with Netlify Cli(will be replaced by github pages soon!)

- npm install netlify-cli -g
- netlify login
- netlify link
- netlify build
- netlify deploy
- netlify deploy --prod

The GPlates Web Service doc is deployed at <https://app.netlify.com/sites/jolly-mclean-06aa7c/overview>.
